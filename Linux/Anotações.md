# O que é o Linux 

O linux é um SO baseado em software livre, onde sua distribuição é gratuita, quando nos referimos ao linux, temos que nos referir ao kernel do linux, sendo o coração dele, o kernel contém tudo que o linux é capaz de realizar, como gerenciamento de hardware, controle de memória, diagnóstico, virtualização, gerenciamento de processos, clustering, gerenciamento de rede, computação em tempo real, gerenciamento de usuários e permissões, interface gráfica, shell, e mais…

# Unix

O Unix foi um sistema operativo, multitarefas e multiusuários que permitia gerenciamento de informações, foi criado de forma minimalista, onde cada tarefa era simples e eficiente, serviu como base para projetar os SO como Linux e Android.

# GNU

O Linux em sí, é o nome de seu próprio kernel, e segue a seguinte organização, hardware -> kernel (linux) -> GNU (Sistemas operativos instalados) / Shell -> Terminal

# Comunidades do Linux

As comunidades são conexões de pessoas por interesse, foi formada comunidades como a Fedora, Debian e OpenSUSE que são comunidades mantidas e ativas, além de serem uma própria distribuição específica rodando em seus SO o próprio kernel do Linux.

# GNOME

O GNOME é a interface gráfica que temos presente no ubuntu por exemplo, ele permite acessar parte dos recursos de forma gráfica e interativa.

# Distribuições do Linux

As distribuições, são versões alteradas/personalizadas do kernel do linux, temos o 

- Debian
- Ubuntu
- Red Hat

# Certificações Linux

Algumas empresas oferecem certificações para provar conhecimento em Linux, as principais certificações são LPI, CompTIA e RedHat Certified.

# Nautilus

É o nome dado para o explorador de arquivos gráfico em um sistema baseado em linux, ele disponibiliza uma interface gráfica e navegável para usuários se localizarem.

# Shell

É um sistema que permite ao usuário se comunicar com o computador através de linhas de comando.

No Shell, o usuário reprcesentado por **$** é um usuário normal, já o usuário representado por **#** é um usuário ROOT.

## Terminal x Shell x Bash

O terminal é a janela que é aberta e permite input de comandos, o shell é o motor por trás das cortinas que converte os comandos em código de máquina e permite o computador entender o que significa, e bash é um dos mais famosos shell.

Para abrir o terminal, podemos apertar **ctrl + alt + t**

# Links Físicos e Simbólicos

O Linux permite criar arquivos de link (como se fossem atalhos) para acessar outros arquivos, eles podem ser classificados em links físicos ou simbólicos, o link físico, realiza um link ao conteúdo do arquivo (se deletar o arquivo original, o conteúdo não será perdido até deletar todos os links físicos relacionados - Esse link não ocupa espaço extra no disco), já o link simbólico, realiza um link ao arquivo original, caso o arquivo original seja deletado, o link simbólico será inutilizado e o conteúdo perdido. Os links são criados através do comando **ln**.
